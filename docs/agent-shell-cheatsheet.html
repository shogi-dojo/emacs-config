Agent chat cheat sheet

Keys for the chat, the compose buffer, the desk sidebar and the details panel. Keys shown are the ones configured in this Emacs setup.

Sending

RETSteer: during a turn it changes course, when idle it sends.
M-RETQueue: sends after the running turn ends.
C-c C-cSend from the compose buffer (viewport).
C-c C-kCancel the compose buffer.
C-c C-pPeek at the last prompt sent.

When to use it: steer to correct the agent mid-task; queue when the next instruction depends on the current turn finishing.

Model, mode and effort

C-c C-vPick the model.
C-c C-mPick the session mode (plan, auto, manual).
C-c C-tPick the thought level (effort).
C-<tab>Cycle the session mode.

When to use it: switch to plan mode before a risky change; drop effort for quick questions.

History and interrupting

M-p / M-nPrevious or next prompt in the compose buffer.
M-rSearch prompt history.
C-c C-cInterrupt the running turn (viewport).
C-c C-oJump to the other chat buffer.

When to use it: search history to reuse an earlier prompt instead of retyping it.

Help

C-c C-hThe compose buffer's help menu.

When to use it: when a key is forgotten, the help menu lists the compose commands in one place.

Desk sidebar

RETOpen the chat at point.
n / NNew chat in this project / in a chosen project.
RRename the chat.
p / aPin or unpin; archive.
cContinue the chat with another account.
iShow the details panel for the chat.
dDelete the chat, after asking.

When to use it: pin the chats you return to; archive finished ones so the list stays short.

Details panel

TABOpen or close the section at point.
g / rRefresh the details.
oOpen the pull request in the browser.
DShow every diff of the chat.

When to use it: check the diffs and the open pull request before asking for a commit.

Terminal and phone

s-` (macOS)
C-c ` in a chat		Open or close the project terminal under the chat. It starts in the chat's folder and is reused for that project.
M-x my/agent-cheatsheetOpen this cheat sheet.
M-x agent-desk-remote-pairShow a pairing code for the Desk Remote phone app.

When to use it: run a quick command in the project without leaving the chat; pair a new phone when the list stops updating.
